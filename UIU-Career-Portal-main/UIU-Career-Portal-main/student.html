Software Engineering Intern

ABC Technologies • 📍 Dhaka, Bangladesh • $300/month

Internship On-Campus Partner C++ Java DSA
🔖 Save Job

Job Description

ABC Technologies is looking for a motivated and passionate Software Engineering Intern to join our core backend and platform engineering team in Dhaka. In this role, you will work alongside senior software architects on scalable microservices, write performant database queries, and contribute to internal automated testing pipelines. This internship provides direct mentorship under UIU alumni leaders and opportunities for full-time conversion upon graduation.

Requirements & Qualifications

  • Enrolled in B.Sc. in CSE / Data Science with completed minimum 100 credits.
  • Minimum CGPA of 3.20 or above.
  • Strong fundamentals in Data Structures, Algorithms, and Object-Oriented Programming (OOP).
  • Proficiency in at least one modern programming language: C++, Java, Python, or TypeScript.
  • Familiarity with Relational Databases (PostgreSQL / MySQL) and Git version control.
  • Excellent analytical mindset and ability to communicate effectively in a team.

Key Responsibilities

  • Assist in designing, building, and deploying modular REST APIs and backend services.
  • Write unit tests, participate in code reviews, and maintain clean software documentation.
  • Investigate system bugs and implement robust bug fixes with senior engineering mentors.
  • Collaborate with Frontend engineers and Product Managers in sprint planning sessions.
  • Explore new architectural patterns, cloud components, and modern DevOps tools.
